# CLAUDE rules

Read aiDocs/context.md for project context.
Follow the coding style in aiDocs/coding-style.md.

This app runs unattended for weeks. Correctness and staying alive beat features.
Verify Windows behaviour by running it, not by reasoning about it — window
styles, tray input and focus rules do not behave the way the docs imply.
Never print, log, or commit a token. Ask before adding a dependency.
Be concise.
